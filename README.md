# skills

Claude Code skills for working with Softlight.

| Skill                                                    | What it does                                           |
| -------------------------------------------------------- | ------------------------------------------------------ |
| [`softlight-walkthrough`](skills/softlight-walkthrough/) | Gets the Softlight share page (walkthrough video) for a pull request. |

To use one, copy its folder into `.claude/skills/` in your repository, or into `~/.claude/skills/`.
